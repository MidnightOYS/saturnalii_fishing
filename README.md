# Гнев глубин

Браузерная игра о рыбалке в мифической Греции. Игрок выходит с причала, наполняет трюм и решает, стоит ли задерживаться ради редкой добычи, пока растёт гнев Посейдона.

| Ветка | Назначение |
| --- | --- |
| `main` | Общие правила ловли, баланса, укладки, риска и экономики. Концепция и сценарий плейтеста. |
| `game/3d` | Действующая версия на Three.js. Исходники в `gnev-glubin-3d/`. |
| `game/isometric` | Версия с фиксированной камерой на Canvas 2D. Исходники в `gnev-glubin-iso/`. |

См. [организацию разработки и производство спрайтов](docs/architecture.md), [концепцию](docs/concept.md) и [сценарий плейтеста](docs/demo-scenario.md).
