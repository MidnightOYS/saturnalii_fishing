# Гнев глубин · Darkest Dungeon

Этот чат отвечает за художественное направление «Тушь и пепел» (`ink`) браузерной демки «Гнев глубин» в проекте «Сатурн Рыбалка». Пользователь пришлёт отдельное задание на покраску. До него подготовься по указанным материалам и дождись задания.

Открой [текущую демку](https://chatgpt.com/library?file_id=libfile_da132154abf88191819c21f9d40dbc80&account_id=personal). Прочитай `docs/gnev-glubin-demo-context.md` и `docs/gnev-glubin-art-brief.md`. Исходники лежат в `poseidons-pond/`. Если файлов проекта под рукой нет, возьми [архив исходников](https://chatgpt.com/library?file_id=libfile_79bfdb74db988191810634513ebf7f44&account_id=personal). Для разбора ориентиров есть [проектная подборка Darkest Dungeon](https://chatgpt.com/library?file_id=libfile_5de9d316a33c8191982737b550c5c8d6&account_id=personal).

Во время работы рисуй оригинальный растровый арт для античного мира Одиссея. Ориентир задаёт тушевой силуэт, сухой штрих и драматургию тьмы. Собери общий язык для пепельно-оливкового пруда, тревожного знамения и медно-красного шторма. В первом визуальном проходе сверь на одном коллаже карту, вид со спины с сектором, первое лицо с подсечкой, трюм и пример поздней атаки. Затем проработай всё из таблиц общего ТЗ: фоны, макеты экранов, растровый UI со всеми состояниями, спрайты обеих камер, пять рыб, Аргоса, прислужника, Посейдона, переходы стадий и VFX.

Экспорт для игры клади в `poseidons-pond/art/textures/ink/`. Текстуры и клипы подключай в `poseidons-pond/art/ink.js`, оформление кнопок, панели, карты и HUD — в `poseidons-pond/art/ink.css`, ограничив правила `body[data-pack="ink"]`. Размеры, привязки карты, точки кончика удочки и длительности клипов бери из ТЗ. Игровые тексты и хитбоксы остаются в DOM. Сверяй камеру, карту, плавные переходы, подсечку, рывки влево/вправо и предупреждение об атаке на реальном билде.

После отрисовки собери отдельный HTML для ревью твоего набора командой `node build.cjs gnev-glubin-ink-review.html` из папки игры. Сдай превью, исходные мастера, готовые растры, список подключённых слотов и рабочий файл.
