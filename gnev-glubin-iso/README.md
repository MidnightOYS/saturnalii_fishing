# Гнев глубин · Изометрия

Десктопный браузерный прототип на Canvas 2D. Две карты, «Лунная цистерна» и «Бронзовая гавань». Художественный ракурс фиксирован. Объём задают 2D-спрайты, контактные тени, отражения и порядок перекрытий.

## Запуск

Для разработки нужен Node.js 22.12+.

```sh
npm install
npm run dev
npm run build
```

Сборка создаёт веб-версию в `dist/` и отдельный `dist/gnev-glubin-isometric.html` для офлайн-плейтеста. Сохранение прогресса зависит от доступности `localStorage` в браузере.

- **WASD / стрелки** двигают лодку по экрану, **ЛКМ** забрасывает. Кольца на воде обозначают рыбные места.
- **Пробел** подсекает на зелёной зоне. Затем держи **A / ←** или **D / →** против рывка и подматывай **Пробелом**, когда рыба устала.
- В трюме выбери ячейку и при необходимости поверни рыбу клавишей **R**.
- **O** расходует подношение. **F** отпугивает прислужника, когда он подходит к лодке.
- С двумя очками улова подплыви к причалу и нажми **E**. Продай рыбу и почини лодку за 25 драхм, чтобы открыть гавань.

## Исходники

| Файл | Что менять |
| --- | --- |
| `src/maps.js` | Водоём, острова, места ловли и координаты декораций. |
| `src/expedition.js` | Движение лодки, радиус заброса, рыбные места и возвращение к причалу. |
| `src/scene.js` | Отрисовка мира, точки опоры атласа, эффекты воды и перекрытия. |
| `src/main.js` | Ввод, HUD, трюм и сохранение. |
| `../packages/fishing/` | Общие правила и баланс двух версий. |
