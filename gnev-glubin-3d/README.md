# Гнев глубин · 3D

Первый браузерный билд на Three.js, TypeScript и Vite. Цикл и объём описаны в [скоупе](gnev-glubin-3d-scope.md).

## Запуск

Открой `dist/gnev-glubin-3d.html` в браузере с WebGL. У файла нет сетевых зависимостей. Для показа на телефоне можно раздать веб-билд `dist/` по HTTP. Прогресс сохраняется в браузере при доступном `localStorage`.

Для разработки используй Node.js 22.12+.

```sh
npm install
npm run dev
npm run build
```

`npm run build` проверяет TypeScript и создаёт обычный веб-билд в `dist/` и автономный HTML для плейтеста.
Готовый HTML можно скачать из артефакта `gnev-glubin-3d` в [прогоне GitHub Actions для ветки `game/3d`](https://github.com/MidnightOYS/saturnalii_fishing/actions?query=branch%3Agame%2F3d).

Кнопка **Визуал** открывает инспектор вылазки. Во вкладке **Вода** доступны десять режимов, их пресеты и параметры, в том числе спектры Герстнера. Во вкладках света и эффектов можно настроить небо, туман, свет, пену, каустику, эффекты ориентиров и сигналы ловли. Визуальный предпросмотр стадии оставляет игровой гнев и темп вылазки прежними. Настройки сохраняются в браузере, водные настройки также можно переносить через JSON.

Во вкладке **Микродетали** можно сочетать десять слоёв на дне, под водой, на поверхности и в воздухе. У каждого слоя своя интенсивность. Во вкладке **Фильтры** можно выбрать один из десяти экранных пресетов и настроить его интенсивность. Микродетали и фильтры изначально выключены.

При переходе в перспективную камеру режимы преломления, бликов и прибоя временно используют Герстнер с согласованным цветом воды. При возврате к навигационной камере восстанавливается выбранный режим с его настройками.

Отдельный стенд `dist/gnev-glubin-water-collection.html` объединяет все десять режимов. В режиме разработки он доступен по `/water-collection.html`. Сборка также выпускает исходные стенды воды, акварели, преломления и слоёв. См. [описание первого стенда](WATER.md).

## Игровой проход

1. На Итаке нажми на лодку, выбери Лунный водосбор и выйди на воду.
2. Управляй лодкой клавишами **WASD**, меняй масштаб колесом мыши. Удерживай **ЛКМ**, чтобы выбрать дальность заброса. Попади поплавком внутрь рыбного круга. Косяк меняет место после поимки, близкого промаха или подхода лодки вплотную.
3. Подсекай **Пробелом**, когда риска войдёт в зелёную зону. Держи **A / ←** или **D / →** против рывка рыбы и подматывай пробелом в окно слабости. Уложи рыбу в трюм, поверни клавишей **R** или выпусти её. **Tab** открывает трюм, время на воде и угрозы приостанавливаются. Заполненный трюм замедляет лодку.
4. Красная полоса предупреждает о движущейся волне. В свободном плавании **Пробел** ускоряет лодку, а удержание **ПКМ** натягивает лук. Отпусти кнопку, чтобы выстрелить по прямой. Заброс, рывок и выстрел тратят по 40% общего запаса выносливости.
5. Волны идут с начала вылазки, с 50% гнева появляются чудовища, с 90% начинается критическая стадия. При 100% или разрушении корпуса улов текущей вылазки теряется. Для успешного выхода подведи лодку к золотому кругу у причала и нажми **На Итаку**.
6. На рынке продай доставленный улов. Каждая рыба после первой добавляет 12% к цене партии данной вылазки, максимум 48%. На лодочной станции почини корпус, который сохраняет повреждения между рейсами.

На телефоне коснись воды, чтобы направить лодку. **Заброс** и **Лук** меняют действие следующего касания. Для рыбалки коснись воды у косяка, для выстрела — цели. При поклёвке нажми **Подсечь** в зелёной зоне, затем удерживай нужную стрелку против рывка и кнопку **Подматывать**, когда рыба устанет.

Венец глубин клюёт во временном фиолетовом косяке. С 50% гнева подсечка в таком косяке может привлечь чудовище. Если косяк исчез после заброса, вываживание можно закончить.

Клик по дому Полифема на нижней террасе или по его метке открывает пари. Для ставки нужны одна рыба и 3 драхмы. Нажми **Зафиксировать** или **Пробел**, пока пасть открыта, чтобы получить цену рыбы с текущим множителем. При укусе рыба возвращается повреждённой и дешевеет. В лавке можно продать одну рыбу и оставить остальной улов для ставок.

## Хаб Итаки

Рыбацкий рынок покупает улов и открывает улучшенные удочки, лодочная станция чинит и усиливает лодку и расширяет трюм. Доска выдаёт награды за задачи, святилище замедляет рост гнева, а построенная обсерватория открывает исследование Гавани затонувшего лика. Здания, лодку и их подписи можно нажимать. На узком экране подписи собираются в панель действий.

Хаб использует GLB из комплекта Итаки в `public/models/ithaca/`. Камера, места лавки, мастерской и лодки берутся из якорей `dock.glb`. Игровой корпус из `public/models/blind-eye/` швартуется на том же якоре, чтобы на Итаке были видны установленные вёсла или парус.

Модели лодки лежат в `public/models/blind-eye/`. Корпус у причала и на воде один. Вёсла используют один GLB, оснастка крепится в гнездо мачты и загружается при открытии прежнего сохранения с парусом. В автономном HTML модели встроены для запуска без сети.

Геометрия вылазок и разметка лежат в `public/models/locations/`. GLB содержит окружение и материалы, layout JSON задаёт берега, препятствия, камеры, старт и свет. `src/expedition.ts` использует эту разметку для навигации, рыбных мест и боя. Рыбалка использует общие правила в `packages/fishing/`. Геометрия трюма и экономика артели определены в `src/cargo.ts` и `src/artel.ts`.

Модели противников лежат в `public/models/enemies/`. В Лунном водосборе встречаются Гиппокамп и Каркинос, в Гавани затонувшего лика — Харибда и Критский бык.

`src/scene.ts` связывает камеры, локацию и воду. Параметры поверхности участвуют и в рендере, и в расчёте положения лодки и поплавка. Для замены сцены обновляйте GLB и layout вместе.
