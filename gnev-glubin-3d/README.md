# Гнев глубин · 3D

Первый браузерный билд на Three.js, TypeScript и Vite. Цикл и объём описаны в [скоупе](gnev-glubin-3d-scope.md).

## Запуск

Открой `dist/gnev-glubin-3d.html` в десктопном браузере с WebGL. У файла нет сетевых зависимостей. Прогресс сохраняется в браузере при доступном `localStorage`.

Для разработки используй Node.js 22.12+.

```sh
npm install
npm run dev
npm run build
```

`npm run build` проверяет TypeScript и создаёт обычный веб-билд в `dist/` и автономный HTML для плейтеста.

Кнопка **Вода** в игровом интерфейсе открывает инспектор материала. Можно менять режим и пресет прямо во время вылазки, редактировать параметры, импортировать и экспортировать JSON. Настройки каждого режима сохраняются в браузере. Гнев настраивает интенсивность воды по ходу вылазки. При переходе в перспективную камеру режимы преломления, бликов и прибоя временно используют Герстнер, а при возврате восстанавливаются.

Отдельный стенд `dist/gnev-glubin-water-collection.html` объединяет все десять режимов. В режиме разработки он доступен по `/water-collection.html`. Сборка также выпускает исходные стенды воды, акварели, преломления и слоёв. См. [описание первого стенда](WATER.md).

## Игровой проход

1. Нажми на лодку на причале, выбери Лунный водосбор и выйди на воду.
2. Управляй лодкой клавишами **WASD**. Наведи мышь в сторону рыбного места и удерживай **ЛКМ**. Дальность циклически меняется от 2,2 до 10 м. Отпусти кнопку, когда кольцо попадёт в круг с рыбой. Поплавок полетит по дуге. Камера переключится на первое лицо, когда он попадёт в рыбное место. При промахе лодка сразу доступна для управления. При поклёвке подсекай **Пробелом**, когда риска попадёт в зелёную зону.
3. Держи **A / ←** или **D / →** против рывка рыбы. Подматывай пробелом, пока рыба устала. После поимки уложи рыбу в трюм. **R** поворачивает её.
4. Когда прислужник поднимется из воды, нажми **F**, чтобы достать лук. Наведи мышь, удерживай **ЛКМ** и отпусти для выстрела. Чем сильнее натяжение, тем дальше летит стрела по дуге. **O** расходует подношение.
5. Набери два очка квоты, вернись на причал и продай улов в лавке. Ремонт за 25 драхм откроет Гавань затонувшего лика в меню лодки.

Геометрия вылазок и разметка лежат в `public/models/locations/`. GLB содержит окружение и материалы, layout JSON задаёт берега, препятствия, камеры, старт и свет. `src/expedition.ts` использует эту разметку для навигации, рыбных мест и боя. Баланс, трюм и экономика используют общие правила в `packages/fishing/`.

`src/scene.ts` связывает камеры, локацию и воду. Параметры поверхности участвуют и в рендере, и в расчёте положения лодки и поплавка. Для замены сцены обновляйте GLB и layout вместе.
